## 手順

### 通読(`docs/stages/08-integration.md`)

担当: 読み手の役のセッション。

読むのは、ビルドした実物である。スライド仕様ではなく、読み手が実際に目にするものを、順に読む。スライドの画像を読むか、実物から抜き出した文字を読むかは、試作で決める。口頭の資料の「発表の通し」の場面では、ノートも読む。

セッションは、次の状態を持ち越す。

- ここまでに定義された語
- ここまでに示された事実と、納得した主張
- まだ答えられていない疑問
- まだ果たされていない約束(「後で述べる」とされた内容、目次に挙げられた内容)
- 示された枠組み(「3つの観点で評価する」など)と、それが後で使われたか
- 説明に使われた例と、想定の場面
- 冒頭で示された結論

1枚ごとに、次を行う。

1. そのスライドが、状態にないものを前提にしていないかを確かめる。
2. ブリーフの読み手の水準で、そのスライドを理解できたかを記録する。
3. エラーがあれば、種類と、食い違う相手の箇所を添えて記録する。
4. 状態を更新し、何が増えたかを記録する。

章の終わりごとに、状態を保存する。状態を明示して持ち越すので、章ごとに区切って実行でき、後から途中の章から再実行できる。

実行の記録(スライドごとの状態とエラー)は、成果物として残す。

### 通読で見つけるもの(`docs/stages/08-integration.md`)

読み手の役のセッションが、状態と照らして見つける。

| 区分 | エラー | 内容 |
|---|---|---|
| 前提 | 未定義の語 | まだ説明されていない語や略語が出てくる |
| 前提 | 専門的すぎる説明 | 説明はあるが、ブリーフの読み手の水準では理解できない |
| 前提 | 前提の先取り | まだ示されていない事実や主張を、既知のものとして使っている |
| 筋 | 既出との矛盾 | 前のスライドで述べたことと食い違う |
| 筋 | 飛躍 | 前のスライドから、なぜ次の話になるのかが分からない |
| 筋 | 停滞 | 読む前と後で、読み手の状態が変わらない。理解が深まらない |
| 筋 | 繰り返し | 既に述べたことを、初めてのように述べ直している。1枚の中で、要点と同じことを別の場所でもう一度述べている |
| 筋 | 枠組みの放棄 | 冒頭で示した観点や分類が、後で使われない。または、別の観点に入れ替わる |
| 筋 | 結論のぶれ | 冒頭の結論、結びの結論、要約の結論が食い違う。要約が本編より強いことを述べている |
| 筋 | 語の意味のずれ | 同じ語が、場所によって違う意味で使われる |
| 筋 | 抽象度の急変 | 方針の話から、橋渡しなしに細部の話に移る。またはその逆 |
| 筋 | 例の不統一 | 説明に使う例や想定の場面が、断りなく入れ替わる |
| 回収 | 約束の未回収 | 「後で述べる」とした内容や、目次に挙げた内容が出てこない |
| 回収 | 問いの置き去り | 途中で読み手に抱かせた疑問に、最後まで答えていない |
| 回収 | 依頼の曖昧 | 読み終えても、何を求められているかが分からない |
| 負担 | 水準の揺れ | あるスライドは初歩から説明し、別のスライドは専門知識を前提にする |
| 負担 | 現在地の喪失 | 今どの章のどの話なのかが分からなくなる |
| 作法 | 作法の変化 | 章が変わると、文体、図の描き方、数値の書き方、色の使い方が変わる |
| 到達点 | 到達点との不一致 | 章の出口の状態が、定めた到達点と違う |
| 形 | 形と中身の不一致 | スライドの形から読み取れる関係(まとまり、対比、順序など)が、中身にない。基準の分からないグルーピングを含む |
| 形 | 要点と図の不一致 | 図や表が、要点の述べていることを示していない |
| 形 | 注目する箇所の不明 | 図や表のどこを見ればよいかが分からない |
| 文 | 意味の取れない文 | 主語がない、語の関係が分からないなどで、文の意味が取れない |
| 文 | くどい文 | 同じことを言い換えて繰り返す。読み飛ばしても意味が変わらない語が多い |
| 語 | 同じものを指す別の語 | 違う語が、同じ対象を指しているように読める |
