## 手順

### 規則の追加と整理(`docs/style-rules.md`)

担当: 設計セッション。

規則を足すたびに、既存の規則との整理と統合を行う。

1. **起案**: 指摘から規則の案を作る。
2. **照合**: 既存の全ての規則と比べ、次のいずれかを判定する。

   | 関係 | 対応 |
   |---|---|
   | 重複(同じことを言っている) | 1つにまとめる |
   | 矛盾(両立しない) | どちらを残すかをユーザーが決める |
   | 包含(一方が他方の特殊な場合) | 一般の規則と例外の形に組み直す |
   | 共通の原理がある(個別の規則が複数並ぶ) | 1つの規則に一般化する |

3. **影響の確認**: 整理後の規則を現在の資料に当て、違反になるスライドの一覧を出す。
4. **承認**: ユーザーが、整理後の規則と影響を見て承認する。
5. **反映**: 規則を更新し、違反になったスライドを直す。

整理は規則の数を減らす方向で行う。文章の規則より、表現の対応表や語彙表のような、機械で検査できる構造への組み込みを優先する。
