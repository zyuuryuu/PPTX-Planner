## 手順

### 工程1 探索の前文(`docs/stages/01-exploration.md`)

問いに答えるための事実を集める。収集の手段(Web検索、資料の読み込み、ユーザーへの聞き取り)は、この文書では定めない。定めるのは、何を調べるか、いつ終えるか、集めた結果が満たす条件である。

仮の結論に合う事実だけを集めることを防ぐため、次の3つを行う。

- 探索の範囲を、仮の結論ではなく問いから決める。
- 収集セッションに、仮説を見せない。
- 対立する仮説を置き、それぞれを支持する事実と否定する事実を記録する。

### 仮説の一覧 `01-hypotheses.yaml`(`docs/stages/01-exploration.md`)

仮の結論と、それに対立する仮説を1つ以上書く。対立する仮説は、逆の結論や「何もしない」などである。

```yaml
- id: H1
  statement: 〇〇事業は、△△に絞って継続すべきである
  proposed_by: user   # user(ユーザーが持っていた結論) / session(設計セッションが立てた)
- id: H2
  statement: 〇〇事業は撤退すべきである
  proposed_by: session
```
