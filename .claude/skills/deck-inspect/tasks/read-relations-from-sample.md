### 含意の語彙(`docs/visual-grammar.md`)

形が伝える関係を、次の語彙で表す。型の定義と、スライドごとの立証の設計が、この語彙を使う。

| 識別子 | 意味 |
|---|---|
| `grouped` | 同じ仲間である |
| `partition` | 全体を、1つの基準で漏れなく重なりなく分けている |
| `equal-weight` | 互いに同じ重みである |
| `comparable` | 同じ観点で比べられる |
| `ordered` | 順序がある(時間、手順、優先) |
| `causal` | 一方が他方の原因である |
| `hierarchical` | 上位と下位の関係がある |
| `cyclic` | 最後から最初に戻る |
| `connected` | 何らかの関係がある |
| `proportional` | 見た目の量が、数値に比例する |
| `independent-axes` | 2つの軸が互いに独立している |
| `distinct-kinds` | 種類が違う |
| `emphasized` | ほかより重要である |
| `opposed` | 2つが対立している、または対になっている |
| `contained` | 一方が他方に含まれる |
| `shared` | 共通する部分がある |
| `ascending` | 段階を追って高まる |
| `main-and-sub` | 一方が主で、他方が補足である |

### 形からの読み取り(`docs/visual-grammar.md`)

型の見本を作った段階で、検査セッションに見本の画像だけを見せ、項目の間にどんな関係があると読み取れるかを含意の語彙で答えさせる。答えが型の `implies` と合わなければ、型の定義か描画の実装を直す。これは型ごとに1回行う。スライドごとには行わない。
