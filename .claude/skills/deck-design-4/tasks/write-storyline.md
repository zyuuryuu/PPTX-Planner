### 工程4 ストーリーラインの前文(`docs/stages/04-storyline.md`)

全ての章のスライドの題と要点を、1つのセッションで決める。題は話題を示し、要点は読み手に理解してほしいことを述べる。2つを別の項目として持つ。全体を一度に扱うことで、章をまたぐ要点の重複と矛盾をこの段階で防ぐ。

題と要点の書き方は[文章の書き方](../../../../docs/writing.md)に、要点のないスライド、節の要点を載せるスライド、スライドの区分は[語彙と区分](../../../../docs/vocabulary.md)に定める。

### スライドの題と要点の一覧 `04-storyline.yaml`(`docs/stages/04-storyline.md`)

```yaml
- id: ch2-s1
  chapter: ch2
  section: ch2-2               # 章構成で決めた節
  question: 伸びは続いているのか                 # 読み手が抱く問い
  title: △△領域の年ごとの市場規模               # 題
  point: △△の領域の市場規模は、5年続けて前の年を上回った   # 要点。問いへの答え
  qualifiers: [国内]           # 要点の文に入れきれない限定
  provenance: cited            # 出どころ。資料の型の定義が区別を求める資料だけに書く。cited(出典のある事実) / proposal(案) / practice(今の運用)
  from: [Q1.1]                 # 要点の素材にした、問いごとの答え
  evidence: [F015]
- id: ch2-s2
  chapter: ch2
  section: ch2-2
  title: △△領域の範囲と集計の方法
  point: null                  # 要点のないスライド
  role: detail                 # 役割。detail(詳しい説明) / exercise(演習の問題) / reference(参照用)
- id: ch2-s3
  chapter: ch2
  section: ch2-2
  question: 5年間でどれだけ大きくなったか
  title: 5年間の規模の変化
  point_from: section          # 節の要点を引く。自分の要点は書かない
  from: [Q1.1]
  evidence: [F015, F016]
- id: ch2-s4
  chapter: ch2
  section: ch2-3
  question: 伸びはどの地域でも同じか
  title: 地域ごとの伸び
  point_from: section          # スライドが1枚だけの節
  from: [Q1.3]
  evidence: [F033]
  contradiction: F033          # 結論を否定する事実に触れるスライドでは、その事実
- id: ap-s1
  chapter: appendix
  appendix_of: ch2-s1          # 付録のスライドでは、本編のどのスライドを補うか
  question: 伸びているのは大手だけではないか
  title: 新規参入の件数
  point: 新規参入の件数も3年で2倍に増えている
  from: [Q1.2]
  evidence: [F021]
  objection: {claim: C1, index: 0}   # 主張の骨子の反論に答えるスライドでは、その反論
```

以下では、`point` を書いたスライドと、節の要点を引くスライドを、要点を持つスライドと呼ぶ。

資料の型の定義が必ず置くと定めるスライド(`required_slides`)には、`required` にその `id` を書く。

この一覧に書くのは、本編と付録の、中身のあるスライドである。自動で作るスライドは書かない。

章の中は、次の順になる。

1. 章扉。
2. 節ごとに、本編のスライド。節のまとめを置く節では、節の最後に置く。
3. 章のまとめ。

### 1. 読み手の問いを書き出す(`docs/stages/04-storyline.md`)

担当: 設計セッション。

節ごとに、節の要点を読んだ読み手が抱く問いを、抱く順に書き出す。ブリーフの「読み手が既に知っていること」に答えがある問いは、書かない。ブリーフの「読み手の立場と懸念」にある懸念は、問いとして含める。

### 2. 問いに、題と要点で答える(`docs/stages/04-storyline.md`)

担当: 設計セッション。

1つの問いに、1枚のスライドで答える。要点は、その問いへの答えの文とする。題は、そのスライドの話題とする。

要点の素材は、工程2の問いごとの答えから取る。節の要点の素材にした答えと、その下にある答えが候補になる。白紙から要点を考えない。素材にした答えを `from` に書く。

該当する答えがない問いは、探索が足りていない。調査依頼を出して工程1に戻るか、その問いを外す。

要点の文に入れきれない限定は、`qualifiers` に書く。

資料の型の定義の `annotation` が出どころの区別を求める資料では、スライドごとに、出どころを `provenance` に書く。値は機械で導かない。設計セッションが書く。

### 3. 要点のないスライドを足す(`docs/stages/04-storyline.md`)

担当: 設計セッション。

節の要点を理解するために要る説明、演習の問題、参照用の一覧は、要点のないスライドとして足し、役割を書く。

### 4. 節の要点を載せるスライドを決める(`docs/stages/04-storyline.md`)

担当: 設計セッション。

[語彙と区分](../../../../docs/vocabulary.md)の表に当てはめる。節の最後のスライドが載せる節では、そのスライドに `point_from: section` を書く。

### 5. 必ず置くスライドを入れる(`docs/stages/04-storyline.md`)

担当: 設計セッション。

資料の型の定義の `required_slides` のスライドを、合う節に入れる。

### 6. 枚数を章構成の配分に合わせる(`docs/stages/04-storyline.md`)

担当: 設計セッション。

章の枚数が章構成の配分を超えたら、除去の検査で残す根拠の弱いスライドから、付録に回すか捨てる。配分を増やす場合と、節を足す、分ける、まとめる場合は、工程3に戻ってユーザーの承認を取り直す。

## 検査

### 満たす合格条件

成果物は、次の条件を満たす。括弧の中は、判定者である。「警告」とある条件は、合否にしない。

- `K04-01` 全てのスライドに、題がある(機械)。
- `K04-02` 資料の型の定義の `annotation` が出どころの区別を求める資料では、全てのスライドに `provenance` がある。`cited` とした、要点を持つスライドに、`evidence` がある(機械)。
- `K04-03` 全てのスライドが、要点を書く、節の要点を引く、要点を持たずに役割を書く、のいずれか1つの形である(機械)。
- `K04-04` 本編の全てのスライドが、章構成にある節に入っている。章構成の全ての節に、スライドが1枚以上ある(機械)。
- `K04-05` 節の項の数が、資料の表現規約の `section_max_slides` 以下である(機械)。
- `K04-06` 節の要点を載せるスライドが、[語彙と区分](../../../../docs/vocabulary.md)の表の通りである。節の要点を引くスライドは、節の最後のスライドだけである(機械)。
- `K04-07` 資料の型の定義の `required_slides` の全てに、`required` でそれを参照するスライドがある(機械)。
- `K04-08` 書き方(`form`)の定めがあるスライドは、その通りに書かれている(検査セッション)。
- `K04-09` 章ごとの枚数が、章構成の配分以下である。自動で作るスライドの枚数は、別に数えてユーザーに示す(機械)。
- `K04-10` 付録の全てのスライドに `appendix_of` がある(機械)。
- `K04-11` 章構成で付録に回すとした答えの全てに、`from` でそれを参照する付録のスライドがある。章構成の `objections` の全てに、`objection` でそれを参照するスライドが、決めた置き場(本編または付録)にある(機械)。
- `K04-12` 章構成の `contradictions` の全てに、`contradiction` でそれを参照するスライドが、章構成が決めた章にある。そのスライドの `evidence` が、その事実を含む(機械)。
- `K04-13` 要点を持つスライドに、問いが1つある(機械)。
- `K04-14` 本論の章の、要点を持つ全てのスライドに、`from` と `evidence` がある(機械)。
- `K04-15` 題と要点が、[文章の書き方](../../../../docs/writing.md)の機械で測る検査と、[使う語彙](../../../../docs/terms.md)の検査を通る。新しい語は、語彙表に登録されている(機械)。
- `K04-16` 要点の中の数値が、そのスライドの `evidence` の事実の値と一致する(機械。単位と表記を正規化して照合する)。
- `K04-17` 要点が、2つの主張をつないでいない。機械が「また」「および」などの接続を含む要点を挙げ、検査セッションが判定する(機械と検査セッション)。
- `K04-18` 要点どうしが矛盾していない。同じ事実、同じ対象を扱う要点の組を機械が挙げ、検査セッションが確かめる(検査セッション)。
- `K04-19` 要点が、`qualifiers` と合わせて、根拠の事実の限定を落としていない(検査セッション。重大な検査)。
- `K04-20` 要点が、そのスライドの問いに答えている(検査セッション)。
- `K04-21` 題が、そのスライドの話題を示している。要点の言い換えになっていない(検査セッション)。
- `K04-22` [題と要点の通読](../../../../docs/checks.md)の3段目を通る(検査セッション)。
- `K04-23` 同じことを述べる要点が複数ない(検査セッション)。
- `K04-24` 全ての要点が、否定の検査と具体性の検査を通る(検査セッション)。 [定義](../../../../docs/checks.md#意味の検査)
- `K04-25` 本編の全てのスライドが除去の検査を通る。通らないスライドは、付録に回すか捨てる(検査セッション)。 [定義](../../../../docs/checks.md#意味の検査)
- `KX-01` 1文の字数が、項目の種類ごとに定める上限以下である(機械)。 [定義](../../../../docs/writing.md#機械で測るもの)
- `KX-02` 1文の読点の数が、上限以下である(機械)。 [定義](../../../../docs/writing.md#機械で測るもの)
- `KX-03` 「の」の連続と、同じ助詞の重なりが、連続する回数の上限以下である(機械)。 [定義](../../../../docs/writing.md#機械で測るもの)
- `KX-04` 漢字の連なりが、連続する字数の上限以下である(機械)。 [定義](../../../../docs/writing.md#機械で測るもの)
- `KX-05` 辞書にある冗長な言い回しを含まない(機械)。 [定義](../../../../docs/writing.md#機械で測るもの)
- `KX-06` 辞書にある、中身のない形容と強調を含まない(機械)。 [定義](../../../../docs/writing.md#機械で測るもの)
- `KX-07` 辞書にある書き出しの決まり文句(「一言で言うと」「結論から言うと」「要するに」「端的に言えば」など)を含まない(機械)。 [定義](../../../../docs/writing.md#機械で測るもの)
- `KX-08` 辞書にある、LLMに多い語を含まない(機械)。 [定義](../../../../docs/writing.md#機械で測るもの)
- `KX-09` ぼかし(「など」「等」「といった」)の数が、上限以下である(機械)。 [定義](../../../../docs/writing.md#機械で測るもの)
- `KX-10` 「また」「さらに」「加えて」で始まる文の割合が、上限以下である(機械)。 [定義](../../../../docs/writing.md#機械で測るもの)
- `KX-11` 近い位置での同じ語の繰り返しの回数が、上限以下である(機械)。 [定義](../../../../docs/writing.md#機械で測るもの)
- `KX-12` です・ます調と、である調が混在していない(機械)。 [定義](../../../../docs/writing.md#機械で測るもの)
- `KX-13` 題が名詞で終わる。句点がない。字数が上限以下である(機械)。 [定義](../../../../docs/writing.md#項目ごとの書き方)
- `KX-14` 要点が1文である。文末が「がわかる」「について」「すべき」でない。字数が、2行に収まる上限以下である(機械)。 [定義](../../../../docs/writing.md#項目ごとの書き方)
- `KX-15` 読み手に見せる文に、内部のIDがない。IDの書式に合う文字列が、`{}` で囲んだ参照のほかにない(機械)。 [定義](../../../../docs/writing.md#内部のid)
- `KX-16` 全角の数字と英字、半角の括弧と句読点、「表記」の決まりに合わない句点がない(機械)。 [定義](../../../../docs/writing.md#表記)
- `KX-17` 全ての文から、名詞と動作を指す語を機械的に抜き出し、語彙表、`allowed` と照合する。扱いは、上の「厳しさの段階」の表による(機械)。 [定義](../../../../docs/terms.md#厳しさの段階)
- `KX-18` `banned` の語を含まない(機械)。 [定義](../../../../docs/terms.md#厳しさの段階)
- `KX-19` 表記の揺れ(長音の有無、送り仮名、全角と半角)を、正規化して語彙表と照合する(機械)。 [定義](../../../../docs/terms.md)
