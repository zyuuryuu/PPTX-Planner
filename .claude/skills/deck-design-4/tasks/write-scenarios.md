### 場面と読み方(`docs/stages/08-integration.md`)

| 場面 | 読み方 |
|---|---|
| 主な読み手の通読 | ブリーフの主な読み手として、最初から最後まで読む |
| 反対の立場の通読 | 結論に懐疑的な読み手として読む |
| 要約だけ | 要約のスライドだけを読む |
| 題と要点だけ | 機械が抜き出した、章、節、スライドの題と要点の一覧を、[題と要点の通読](../../../../docs/checks.md)の3段で読む |
| 途中から | 配布する資料で、指定した章から読み始める |
| 発表の通し | 口頭の資料で、ノートを話として順に読む |
| 過去の指摘 | 過去に受けた指摘が再発していないかを、該当の箇所で確かめる |

### 期待する結果(`docs/stages/08-integration.md`)

| 場面 | 期待する結果 |
|---|---|
| 主な読み手の通読 | 各章の出口で、定めた到達点の通りの状態になる。最後に、結論と、求められている行動を述べられる。未回答の疑問がない |
| 反対の立場の通読 | 主張の骨子に書いた反論の全てに、本編か付録で答えを得る |
| 要約だけ | 結論と、その理由を述べられる |
| 題と要点だけ | 章の要点から結論を、節の要点から章の要点を、スライドの要点から節の要点を述べられる。題に重複がなく、話題の順が自然である |
| 途中から | その章の入口の状態を、章扉と、前の章の要点を載せるスライドから得られる。章のまとめがこれに当たる。節が1つだけの章では、節の要点を載せるスライドが当たる |
| 発表の通し | 話が切れずにつながる。全体の時間が、ブリーフの制約に収まる |
| 過去の指摘 | 再発していない |
