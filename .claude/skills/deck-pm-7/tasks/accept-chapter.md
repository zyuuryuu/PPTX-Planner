### 3. 章を受け入れる(`docs/stages/07-slide-spec.md`)

担当: PM。

PMが章を受け入れるのは、保留のスライドがなくなり、合格条件(機械の検査、検査セッションの検査、章の受け入れの条件)を全て満たしたときである。章の受け入れを、状態の記録に書く([不合格と修正の手順](../../../../docs/rework.md)の「承認の記録」)。

### 渡すもの(`docs/stages/08-integration.md`)

担当: PM。

読み手の役のセッションに、ブリーフの読み手の情報(立場、既に知っていること、懸念)だけを渡す。設計の成果物は渡さない。例外として、前の章が未完成の場合と、途中の章から再実行する場合は、その章の入口の状態を渡す。「題と要点だけ」の場面では、機械が抜き出した、題と要点の一覧を渡す。場面の指定は、テストの場面から期待する結果を除いた写しで渡す。

### 出口の状態の照合(`docs/stages/08-integration.md`)

担当: PM。

章の出口の状態が到達点と合うかどうかは、読み手の役のセッションが書いた状態と、章の前提と到達点を、PMが機械的に照合して確かめる。

### 状態の記録(`docs/rework.md`)

書くのは、機械の命令だけである。検査のコマンドが、検査の記録と成果物の差分から書く。承認は、承認を記録する命令が書く。人とセッションは、直接は書かない。状態について事情の説明が要るときは、設計セッションが設計の判断の記録に書く。

```yaml
artifacts:
  01-sources.yaml:
    state: checked           # draft / checked / approved / invalid
    commit: 3f2a9c1
    rounds: 2
    checks: [checks/inspect-sources--all--2.yaml]
  02-claims.yaml:
    state: approved
    commit: 8b1d44e
    approved_by: user
    approved_on: 2026-11-23
slides:
  ch2-s3:
    state: invalid
    reason: F015 の値が変わった
```

| `state` | 意味 |
|---|---|
| `draft` | 作成中。合否にする検査のうち、通っていないものがある |
| `checked` | 検査済み。`commit` の版が、合否にする検査の全てに通った |
| `approved` | 承認済み。`commit` の版を、`approved_by` の者が承認した |
| `invalid` | 無効。合格または承認の後に、前提にした上流の項目か、成果物そのものが変わった |

- `rounds` は、検査した回数である。往復の回数は、これより1つ少ない。`checks` は、最後の回の検査の記録である。
- `approved_by` は、承認した者である。ユーザーは `user`、章を受け入れたPMは `pm` と書く。
- `slides` は、スライドごとの状態である。無効になった理由を `reason` に書く。
- スライドの保留は、スライド仕様の `status` が持つ。状態の記録には写さない。

## 検査

### 満たす合格条件

成果物は、次の条件を満たす。括弧の中は、判定者である。「警告」とある条件は、合否にしない。

- `K07-39` 受け入れ済みの章とあわせて、同じ言い回しと同じ文型の出現回数を集計する。資料の表現規約の目安を超えた場合は、設計セッションが直し方を決め、章の執筆のセッションに渡す(機械が集計する)。
- `K07-40` 描画上の診断に、文字と背景の色の差、隣り合う色の差、1枚で使う色相の数を含める(機械)。 [定義](../../../../docs/visual-grammar.md#d-知覚の限界)
- `K07-41` その章をビルドし、描画上の診断(文字のあふれ、要素の重なり、描かれなかった内容、文字の大きさの下限)が0件である(機械)。 [定義](../../../../docs/visual-grammar.md#d-知覚の限界)
- `K07-42` 骨組みの資料の該当する章を実物に差し替え、主な読み手の通読をその章について実行する。前の章が未完成の場合は、入口の状態を章の前提と到達点から与える。重大度が高のエラーがなく、章の出口の状態が到達点と合う(読み手の役のセッションが読み、PMが出口の状態と到達点を機械的に照合する)。 [定義](../../../../docs/stages/08-integration.md#実行の方法)
