# ブリーフ

見本の資料。社内の問い合わせ対応にチャットボットを導入するかを、部長に決めてもらう。

## 資料の型
- 状態: 確定

proposal(提案書)

## 伝え方
- 状態: 確定

配布して読ませる

## 主な読み手
- 状態: 確定

管理部の部長

## 副次的な読み手
- 状態: 確定

情報システム部の課長

## 読み手が既に知っていること
- 状態: 確定

問い合わせの窓口が情報システム部にあること

## 読み手の立場と懸念
- 状態: 確定
- 立場: 中立
- 懸念: 費用が見合うのか
- 懸念: 回答の誤りで混乱しないか

## 目的
- 状態: 確定

今は導入するかを迷っている。読んだ後に、来期の導入を承認する。

## 答えるべき問い
- 状態: 確定

社内の問い合わせ対応に、チャットボットを導入すべきか

## 扱わない範囲
- 状態: 確定

社外の顧客からの問い合わせ

## 使われる場面
- 状態: 確定

会議の前に配る。会議で質疑がある

## 書き手の立場
- 状態: 確定

情報システム部の担当者(読み手の部下ではない、他部署の担当者)

## 制約
- 状態: 確定
- 枚数の上限: 16
- 言語: 日本語
- 期限: 2026-12-15

## 外に出せない情報
- 状態: 確定

問い合わせた社員の名前

## 手元の資料
- 状態: 確定

問い合わせ管理システムの集計、試行の報告書、業者の見積書

## 型ごとの追加の項目
- 状態: 未定
- 決める人と時期: 管理部の部長が、工程1の承認までに決める

最終的に決める人は誰か。現状維持や他の案との比較になるか
