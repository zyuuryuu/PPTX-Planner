# 語彙と区分

[目次に戻る](README.md)

## 主張の種類の語彙

Plannerが固定の核を持ち、資料ごとに追加を許す。機械的な検査と、描画の実装への対応づけが、固定の語彙を前提にするためである。

| 区分 | 種類 | 識別子 |
|---|---|---|
| 数量 | 構成比 | `composition` |
| 数量 | 項目の比較 | `item-comparison` |
| 数量 | 推移 | `trend` |
| 数量 | 分布 | `distribution` |
| 数量 | 相関 | `correlation` |
| 概念 | 手順 | `process` |
| 概念 | 構造・階層 | `structure` |
| 概念 | 対比(2案、前後) | `contrast` |
| 概念 | 因果 | `causality` |
| 概念 | 位置づけ(2つの軸の上に対象を置く) | `positioning` |
| 概念 | 並列の列挙 | `list` |
| 概念 | 言い切り(図表を使わず1文で述べる) | `statement` |

数量の5種はZelazny『Say It With Charts』の分類による。語彙の名前と範囲は未確定である。

## スライドの区分

主張の骨子から導かれるスライド(本編)のほかに、次の区分がある。

| 区分 | 例 | 作り方 | 検査 |
|---|---|---|---|
| 導出 | 表紙、目次、章扉、出典の一覧 | ビルドの際に、上流の成果物から機械的に作る | 不要 |
| 半導出 | 要約、章のまとめ、結論と次の一手 | 工程8で、主張の骨子と要約版を材料にLLMが書く。聴衆に合わせた圧縮と強調が要るため、機械的には作らない | 工程8の合格条件 |
| 付録 | 詳細なデータ、本編から外した素材 | 本編と同じ工程で作る。ストーリーラインに、本編のどのスライドを補うかを記録する | 見出しを順に読む検査と除去の検査からは外す。ほかの合格条件は本編と同じ |

## 資料の種類

ブリーフで、資料の目的と伝え方を指定し、合格条件を切り替える。

| 目的 | 読み手に起こしたいこと | 頂点に置くもの | 探索で必ず調べる観点 |
|---|---|---|---|
| 提案書 | 決めてもらう | 提案とその理由 | 何もしない場合、他の案、費用、リスク、反対する立場の論点 |
| 調査報告 | 知ってもらう | 問いへの答え | 範囲の定義、対立する見解、データの限界 |
| 製品紹介 | 関心を持ってもらう | 相手にとっての価値 | 競合する手段、向かない用途 |
| 研修資料 | できるようになってもらう | 受講後にできること | 受講者が陥りやすい誤り |

伝え方は、口頭で説明するか、配布して読ませるかのいずれかである。

研修資料では、主張の骨子の `answer` が学習の目標に、主張が習得する項目に替わる。この読み替えで工程がそのまま使えるかは未検証である。

切り替える条件の候補は、主張の数の上限、1枚あたりの文字数の上限、ノートを必須にするか、スライド上に出典を必ず載せるか、である。資料の種類はこれらの初期値を決め、値そのものは資料の表現規約に置く。具体的な値は未確定である。
