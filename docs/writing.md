# 文章の書き方

[目次に戻る](README.md)

スライドの中の文(見出し、結論1行、説明、ラベル、表のセル、図の注記、ノート)の書き方と、その検査を定める。原則は「必要なことはもれなく書き、必要でないことは一つも書かない」(木下是雄『理科系の作文技術』)である。

## 項目ごとの書き方

| 項目 | 書き方 |
|---|---|
| 見出し | 主張を述べる1文。このスライドが示すこと |
| 結論1行 | 1文。見出しが示したことから、章の主張に対して何が言えるか。見出しの言い換えを書かない |
| 説明 | 1文。見出しの言い換えを書かない |
| ラベル、表のセル | 短い語句。同じ列や同じ並びの中で、形を揃える(全て名詞、または全て文) |
| 図の注記 | 注目させる点に対応するものだけ |
| ノート | 伝え方による(下の節) |

結論1行をスライドに載せるかどうかは、資料の表現規約で決める。載せない場合も、スライド仕様には書く。全体検査とノートで使う。

文の長さ、語調、密度は、工程6で承認した型の見本に合わせる。

## ノート

| 伝え方 | スライド | ノート |
|---|---|---|
| 口頭で説明する | 疎にする。見出しと図で主張が伝わる | 話す内容を書く。図の読み方、強調する点、次のスライドへのつなぎ、想定される質問 |
| 配布して読ませる | 必要なことを全てスライドに載せる | 使わない |

- ノートも、素材台帳にある事実だけを使う。
- スライドは、ノートなしで主張が伝わるようにする。
- ノートは、発表する人が書き手と別の場合を想定して書く。

## 削ってよいものと、削ってはいけないもの

| 区分 | 例 | 扱い |
|---|---|---|
| 飾り | 非常に、様々な、重要な、まず前提として | 消す |
| 冗長な形 | することができる、という形になっている | 同じ意味の短い形にする |
| 限定 | 下の表 | 消さない |

限定にあたるもの:

| 種類 | 例 |
|---|---|
| 条件 | 〜の場合に限り、既定では、〜を有効にしたとき |
| 範囲 | 国内の、v2以降の、検証環境では |
| 数量の幅 | 最大で、少なくとも、約、平均で |
| 主体と対象 | 誰が、何が、何に対して |
| 例外 | ただし、〜を除く、原則として |
| 不確かさ | 〜のおそれがある、〜と見られる |
| 因果と順序を示すつなぎ | 〜のため、〜の後に |

限定を消すと、文は元の事実より強い主張、広い主張、または曖昧な主張に変わる。

素材台帳の事実には、その事実に付いている限定を `qualifiers` として記録する([工程1](stages/01-exploration.md))。

## 技術的な内容の規則

- 仕組みを述べる文では、動作の主体を省かない。「これ」「それ」が指すものを、同じ文の中で分かるようにする。
- 名詞をつなげて圧縮しない。語の間の関係を示す助詞を残す。
- 語彙表にある語を、平易な言い方に置き換えない。読み手が知らない語は、初出で補う。

## 収まらないときの順序

字数の上限に収まらないときは、次の順で対処する。

1. 飾りを消す。
2. 冗長な形を短くする。
3. 文を分ける。または、条件を表の列にするなど、形を変える。
4. 詳細をノートか付録に移し、スライドからは参照する。
5. スライドを分ける。工程4に戻る。

限定を消すことは、どの段階でも行わない。

## 検査

### 機械で測るもの

| 項目 | 方法 |
|---|---|
| 文が長い | 1文の字数の上限。項目の種類ごとに定める |
| 読点が多い | 1文の読点の数の上限 |
| 「の」の連続、同じ助詞の重なり | 連続する回数 |
| 漢字の連なりが長い | 連続する字数の上限 |
| 冗長な言い回し | 辞書との照合 |
| 中身のない形容と強調 | 辞書との照合 |
| LLMに多い語 | 辞書との照合 |
| ぼかし | 「など」「等」「といった」の数 |
| 接続詞の多用 | 「また」「さらに」「加えて」で始まる文の割合 |
| 同じ語の反復 | 近い位置での繰り返しの回数 |
| 文末の不統一 | です・ます調と、である調の混在 |
| 使う語彙 | [使う語彙](terms.md)の検査 |

日本語の文章を機械的に検査する道具(textlintと、その技術文書向けの規則集)を土台にする。上限をスライド向けに厳しくし、辞書を足す。辞書は個人の表現規約に置き、フィードバックで足す。

上限の値は未確定である。口頭の資料のノートでは、字数と読点の上限を緩める。技術的な資料では、1文の字数の上限を緩める。値は資料の型の定義の `limits` に置く。

### 検査セッションが判断するもの

| 検査 | 方法 |
|---|---|
| 裏付けのない文 | スライド仕様と、そのスライドが使う事実だけを渡す。文を1つずつ、事実に裏付けられているかを判定する。「多くの企業が」「近年」のような根拠のない一般化も対象とする |
| 限定の残存 | スライドが使う事実の `qualifiers` が、全て文に残っているかを照合する |
| 削る検査 | 文ごとに、消しても意味が変わらない語を全て挙げる。挙がった語のそれぞれについて、消すと主張が事実より強く、広く、または曖昧になるかを確かめる。ならないものだけを消す。消した後も、文として読めること |
| 重複の検査 | 同じスライドの中で、見出し、結論1行、説明が同じことを繰り返していないか |
| 主体の検査 | 仕組みを述べる文で、動作の主体が書かれているか |
| 読み戻し | 経緯を知らない検査セッションにスライドの文だけを読ませ、意味を完全な文で書き直させる。素材台帳の事実と比べ、条件の脱落や主体の違いがないかを確かめる。対象は、仕組みの記述のスライドと、`qualifiers` を持つ事実を使うスライドとする |

検査セッションの指摘と、執筆のセッションの修正の往復は、資料の表現規約が定める回数を上限とする。超えた場合は、PMがユーザーに上げる。
