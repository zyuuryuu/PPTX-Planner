# 使う語彙

[目次に戻る](README.md)

状態: 仮決め。試作の結果を見て見直す。

用語の揺れを、書いた後に見つけて直す方法では防がない。直す作業そのものが、意味の取り違えを生むためである。設計の間に使う語彙を決め、執筆はその語彙だけで書く。禁じる語を並べるのではなく、使う語を決める。

航空機の整備文書で使われている制限言語(ASD-STE100)と同じ考え方をとる。使ってよい語を辞書で定め、1つの語に1つの意味を割り当て、対象の分野に固有の名称は案件ごとに決めて足す。

## 原則

1. **管理する単位は、語ではなく概念とする。** 1つの概念に1つの語、1つの語に1つの概念を割り当てる。
2. **同じものかどうかを決めるのは人である。** LLMは候補を挙げるところまでとする。
3. **執筆は、登録済みの語だけで書く。** 登録のない語は、機械的な検査で止める。
4. **一括の置き換えと、LLMによる用語の修正をしない。** 違反は、その文を書いたセッションが、その文を直す。

## 成果物

`terms.yaml`(語彙表)。資料の表現規約の一部である。

```yaml
- id: T-customer
  term: 契約企業
  kind: noun                 # noun(対象を指す語) / action(動作を指す語)
  definition: 当社と契約を結んでいる法人
  not: [T-end-user]          # 近いが別の概念
  note: 個人の利用者は「利用者」とする
  defined_in: ch1-s3         # 資料の中で定義するスライド。定義が要らない場合は省く
- id: T-send
  term: 送信する
  kind: action
  definition: 部品が、別の部品にデータを渡す
banned:                      # 使わない語と、その理由
  - term: ユーザー
    reason: 利用者と契約企業の両方を指しうる
    use: [T-customer, T-end-user]
  - term: 連携する
    reason: 何をするのかが決まらない
allowed:                     # 分野に固有ではないが、一般語の辞書にない語。検査で止めない
  - 四半期
```

- 対象とするのは、資料の分野に固有の、対象を指す語と動作を指す語である。一般の語は対象としない。
- 仕組みの定義の要素の名前は、語彙表に自動で含める。
- 2つの意味で使われうる語は、`banned` に入れ、意味ごとに別の語を登録する。

## 作り方

### 設計の時期: 登録する

工程2から5で、主張の骨子、章の主張、見出し、立証の設計に新しい語が出るたびに、設計セッションが語彙表に登録する。これらの成果物は小さく、ユーザーが承認するため、語の数は数十にとどまる。

登録の際、設計セッションは次の候補を挙げ、ユーザーが決める。

- 既にある語と、同じ概念を指していそうな語。
- 2つの意味で使われていそうな語。

### 工程6: 凍結する

型の見本の承認とあわせて、ユーザーが語彙表を承認する。判断が要る候補だけを先に示し、残りは一覧で示す。承認の後は、語彙表を凍結する。

### 製造の時期: 登録済みの語だけで書く

章の作業票に、その章に関わる語と、その定義、近いが別の概念を載せる。

執筆のセッションは、登録のない語が必要になったら、Issueで登録を求める。自分では語彙表を変えない。登録を待つ間、そのスライドは保留にする。

## 検査

- 見出し、結論1行、説明、ラベル、表のセル、ノートから、名詞と動作を指す語を機械的に抜き出す。語彙表の `term` と `allowed`、一般語の辞書のいずれにもない語があれば、通さない(機械)。
- `banned` の語を含まない(機械)。
- 表記の揺れ(長音の有無、送り仮名、全角と半角)を、正規化して語彙表と照合する(機械)。
- 出典の引用、画面に表示されている名前、固有の名称は、検査の対象から外す。これらはデータの上で別の項目(`quote`、`regions` の `label` など)に入っているため、機械的に外せる。
- 語が、定義するスライドより前に使われていない(機械。工程8)。

## 語を後から変える場合

概念を指す語を変える場合に限り、置き換えを機械的に行ってよい。上の原則と検査が最初から守られていれば、古い語は1つの概念だけを指しているためである。置き換えた文は、限定の残存の検査([文章の書き方](writing.md))を受ける。

概念を分ける、または統合する場合は、置き換えを機械的に行わない。該当する文を一覧にし、章の執筆のセッションが1文ずつ直す。

## 残る危険

- 登録済みの語を、違う意味で使う誤りは、機械では見つからない。作業票に定義と近い概念との違いを載せて減らす。
- 一般の語と、分野に固有の語の線引きは、辞書に頼る。最初は誤検出が多い見込みで、`allowed` に足すことで減らす。
- 縛りが強く、文が不自然になる恐れがある。
