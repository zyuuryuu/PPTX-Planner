# 工程4 ストーリーライン

[目次に戻る](../README.md)

全ての章のスライドの見出しを、1つのセッションで決める。見出しは体言止めの題名ではなく、主張を述べる文とする。全体を一度に扱うことで、章をまたぐ主張の重複と矛盾をこの段階で防ぐ。

成果物 `04-storyline.yaml`:

```yaml
- id: ch1-s2
  chapter: ch1
  headline: △△の領域は過去5年、年率8%で伸びている
  evidence: [F015]
```

この時点で骨組みの資料をビルドする。各スライドには見出しと、根拠の事実の `statement` だけが載る。ユーザーはこの資料を見て承認する。

合格条件:

- 1スライドに見出しは1つである(機械)。
- 全てのスライドに `evidence` がある(機械)。
- 章内の見出しを順に読むと、章の `message` が導ける(検査セッションとユーザー)。
- 同じ主張を述べる見出しが複数ない(検査セッション)。
- 全ての見出しが、否定の検査、具体性の検査、語彙と文体の検査を通る(検査セッション)。
- 見出しに、用語集の禁止表記と、表記の規則への違反がない(機械)。
- 見出しの中の数値が、そのスライドの `evidence` の事実と一致する(検査セッション)。
- 全てのスライドが除去の検査を通る。通らないスライドは、付録に回すか捨てる(検査セッション)。
