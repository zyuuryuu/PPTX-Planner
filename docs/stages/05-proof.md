# 工程5 立証設計

[目次に戻る](../README.md)

スライドごとに、見出しを読み手に納得させるために何を見せるかを決める。中身を書く前に行う。全体を1つのセッションで扱う。

成果物 `05-proof.yaml`:

```yaml
- id: ch1-s2
  relation: trend                 # 主張の種類
  show: 全体と△△領域の売上を5年分並べる   # 見せるもの
  focus: 2023年以降の差の広がり          # 注目させる点
  facts: [F015, F016, F040]       # 使う事実
  axis: null                      # 項目をまとめるスライドでは、分類の軸を書く
```

`facts` が足りなければ、調査依頼を出して工程1に戻る。

この時点で仮置きの資料をビルドする。各スライドには見出しと、図の型の仮置き(「ここに5年分の推移」など)が載る。

合格条件:

- `relation` が[主張の種類の語彙](../vocabulary.md)にある(機械)。
- `facts` が全て素材台帳にあり、`verified: true` である(機械)。
- スライド内の要素が除去の検査を通る。`show` が、`focus` に関係しない要素を含まない(検査セッション)。
- 項目をまとめるスライドが、分類の軸の検査を通る(検査セッション)。
- 仮置きの資料を見て、見せ方に同意する(ユーザー)。
- 見出しの復元: 検査セッションに見出しを隠して `show`、`focus`、`facts` だけを見せ、見出しを書かせる。元の見出しと意味が一致する(検査セッション)。
