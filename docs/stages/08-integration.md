# 工程8 全体検査

[目次に戻る](../README.md)

章ごとに書いた仕様を合わせ、章をまたぐ問題を検査する。

検査のために、全スライドの見出しと結論1行だけを並べた要約版 `08-digest.md` を機械的に作る。

要約、章のまとめ、結論と次の一手のスライドは、この工程で書く。主張の骨子と要約版を材料として、全体を扱う1つのセッションで書く。

合格条件:

| 条件 | 判定 |
|---|---|
| 同じ事実が複数のスライドに出ていない。2回目以降は「再掲」と明示したものだけ許す | 機械(事実のIDの使用箇所を集計) |
| 語が、定義するスライドより前に使われていない | 機械(語彙表と初出の位置を照合) |
| 他のスライドへの言及の参照先が存在する | 機械 |
| 全ての図が、仕組みの定義にある要素とつながりだけを含む | 機械 |
| やり取りや状態の遷移の図に出る要素が、構成または要素の関係の図のいずれかにも出る。出ない場合は警告とする | 機械 |
| 全体図と詳細図で、同じ要素の位置と名前が保たれている | 検査セッション(画像を見る) |
| 章をまたいで主張が矛盾していない | 検査セッション(要約版を通読) |
| 結論1行を順に読んで `answer` に至る | 検査セッション(要約版を通読) |
| 要約、章のまとめ、結論と次の一手が、主張の骨子と要約版にない主張や事実を含まない | 検査セッション |

条件を満たさない場合は、問題のあるスライドの仕様(工程7)に戻る。主張の矛盾が見出しに由来する場合は、ストーリーライン(工程4)に戻る。
