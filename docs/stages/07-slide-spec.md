# 工程7 スライド仕様

[目次に戻る](../README.md)

スライドごとに、載せる内容を確定する。章ごと(長い章は節ごと)に1ファイルに分け、それぞれ別の執筆のセッションが書く。進め方は[体制とセッション](../organization.md)に定める。

上流の工程で、見出し、主張の種類、見せるもの、注目させる点、使う事実、型、見本が決まっている。この工程で書くのは、型のデータ、結論1行、説明、ノートである。文の書き方と検査は、[文章の書き方](../writing.md)に定める。

## 成果物

`07-slides/ch2.yaml`(章ごとのスライド仕様):

```yaml
- id: ch2-s1
  status: done               # done(書き終えた) / blocked(保留。Issueの番号を添える)
  headline: △△の領域は過去5年、年率8%で伸びている
  takeaway: 成長は一時的な要因ではなく、5年続いている   # 結論1行。本編のスライドでは必須
  body:
    type: line-chart
    data: {...}
    highlight: series-target  # 強調する要素。立証設計の注目させる点に対応する
  text: 国内市場の{F040}を占めるまでに拡大した   # 数値は事実のIDで参照する
  sources: [F015, F016, F040]
  notes: 口頭で補う説明
```

`text`、`body.data`、`notes` の数値は直接書かず、事実のIDで参照する。ビルドの際に台帳の値に置き換える。`headline` と `takeaway` は、ストーリーラインを人が読めるように数値を直接書いてよい。その数値は、そのスライドの `sources` の事実と一致させる。他のスライドへの言及は、スライドのIDで書く。

画像の型のスライドでは、画像の素材と、注釈を付ける `regions` を参照する。位置は書かない。

```yaml
- id: ch5-s2
  status: done
  headline: 保存の前に、納期の欄を確かめる
  takeaway: 納期が空のまま保存すると、発注が止まる
  body:
    type: annotated-image-steps
    asset: A003
    crop: [due-date-field, save-button]   # この範囲が入るように切り抜く
    scenario: S-order-entry               # 番号は、場面の順から決まる
    notes:
      due-date-field: 納期を入力する
      save-button: 保存を押す
  sources: [A003, F120]
```

## 作り方

1. 執筆のセッションは、章の作業票と、型の見本を読む。
2. スライドごとに、型のデータ、結論1行、説明、ノートを書く。素材台帳にある事実のうち、立証設計がそのスライドに割り当てたものだけを使う。
3. 字数の上限に収まらないときは、[文章の書き方](../writing.md)の「収まらないときの順序」に従う。
4. 上流の成果物の問題に気づいたら、Issueを立て、そのスライドを保留にして、ほかのスライドを進める。推測で埋めない。上流の成果物を自分で直さない。
5. 書き終えたら、検査のコマンドを実行し、完了の報告を返す。

## 合格条件

上流との一致:

- `headline` がストーリーラインと一致する(機械)。
- `body.type` が、表現の対応表が定める型と一致する(機械)。
- `sources` が立証設計の `facts` に含まれる(機械)。
- 図の型のスライドが、立証設計の `view` にある要素、つながり、場面だけを使う(機械)。
- 強調する要素が、立証設計の注目させる点に対応する(検査セッション)。
- 章のブランチが、その章のスライド仕様以外のファイルを変えていない(機械)。

事実:

- `text`、`body.data`、`notes` に、事実のIDによらない数値がない(機械)。
- `headline` と `takeaway` の数値が、`sources` の事実と一致する(検査セッション)。
- 裏付けのない文がない(検査セッション)。
- 限定の残存の検査を通る(検査セッション)。
- 読み戻しの検査を通る。対象のスライドに限る(検査セッション)。

画像:

- 画像の型のスライドが参照する `regions` が、全て画像の素材にある(機械)。
- 位置の出どころが `estimated` の `regions` に付けた注釈について、描いた印の周辺を切り出した画像を見て、印が `label` の対象を指している(検査セッション)。

文:

- [文章の書き方](../writing.md)の機械で測る検査を通る(機械)。
- [使う語彙](../terms.md)の検査を通る(機械)。
- 型の項目ごとの収容量に収まる(機械)。
- 削る検査、重複の検査、主体の検査を通る(検査セッション)。
- ブリーフに「読み手が既に知っている」と書かれた内容の説明を含まない(検査セッション)。
- 型の `implies` が成り立つ中身になっている。立証設計の `holds` と食い違う中身を書いていない(検査セッション)。

状態:

- 保留のスライドの全てに、Issueの番号がある(機械)。
- PMが章を受け入れるのは、保留のスライドがなくなり、上の条件を全て満たしたときである。
