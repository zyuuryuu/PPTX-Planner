# 工程1 探索

[目次に戻る](../README.md)

問いに答えるための事実を集める。収集の手段(Web検索、資料の読み込み、ユーザーへの聞き取り)は、この文書では定めない。定めるのは、何を調べるかと、集めた結果が満たす条件である。

仮の結論に合う事実だけを集めることを防ぐため、次の3つを行う。

- 探索の範囲を、仮の結論ではなく問いから決める。
- 収集セッションに、仮説を見せない。
- 対立する仮説を置き、それぞれを支持する事実と否定する事実を記録する。

成果物 `01-plan.yaml`(探索の計画)は、ブリーフの問いを小さな問いに分解したものである。集める前にユーザーが承認する。

```yaml
- id: Q1
  question: △△の領域の市場は今後も伸びるか
  perspective: null          # 資料の目的が定める観点に対応する場合は、その名前
- id: Q4
  question: 何もしない場合、〇〇事業の収益はどうなるか
  perspective: 何もしない場合
```

計画は、[語彙と区分](../vocabulary.md)が資料の目的ごとに定める観点を全て含む。

成果物 `01-hypotheses.yaml`(仮説の一覧)には、仮の結論と、それに対立する仮説を1つ以上書く。対立する仮説は、逆の結論や「何もしない」などである。

```yaml
- id: H1
  statement: 〇〇事業は、△△に絞って継続すべきである
  origin: user        # user(ユーザーが持っていた結論) / session(設計セッションが立てた)
- id: H2
  statement: 〇〇事業は撤退すべきである
  origin: session
```

成果物 `01-sources.yaml`(素材台帳)の1件:

```yaml
- id: F012
  statement: 2025年の国内市場規模は1.2兆円
  value: 1.2            # 本文から参照する数値。数値でない事実では省く
  unit: 兆円
  kind: fact            # fact(事実) / inference(推測) / opinion(意見) / derived(計算値)
  source: 〇〇白書 2025年版
  locator: p.34 図表2-1  # ページ、URL、節など
  quote: "国内市場は1兆2,000億円に達した"
  origin: 〇〇省の統計    # 元をたどった情報源。別の資料が同じ情報源を引いている場合に、同じ値になる
  answers: [Q1]          # 探索の計画のどの問いに答えるか
  stance: {H1: supports, H2: contradicts}   # 仮説ごとに、supports(支持) / contradicts(否定) / neutral(どちらでもない)
  verified: true        # 検査セッションが引用箇所を確認したか
```

`answers` までは収集セッションが書く。`stance` は、収集の後に設計セッションが書く。

合計や比率などの計算値も、台帳に登録する。計算値は、元の事実が全て `verified: true` で、再計算の結果が一致するときに `verified: true` とする。

```yaml
- id: F040
  statement: △△領域は国内市場の25%を占める
  value: 25
  unit: "%"
  kind: derived
  formula: F013 / F012   # 元になる事実と計算式
  verified: true
```

後の工程で根拠に使えるのは、`verified: true` の `fact` と `derived` だけである。`inference` と `opinion` は根拠に使えない。スライドに載せる場合は、推測または意見であることを文面に明示する。使われない事実が台帳に残ることは問題としない。

調査は設計セッションや執筆セッションから直接行わず、調査依頼として収集セッションに渡す。調査依頼は、探索の計画の問いをそのまま渡す。「Aを裏付ける事実を探せ」のような、結論を含む聞き方をしない。収集セッションは仮説の一覧を読まない。ブリーフに挙げた手元の資料も、収集セッションが読んで台帳に取り込む。調査依頼の項目:

- 知りたいこと(1文の問い)
- 探索の計画のどの問いに対応するか
- 返す形式(素材台帳の書式)
- 見つからなかった場合は「見つからない」と返すこと

合格条件:

- 全ての `fact` に `source`、`locator`、`quote` がある(機械)。
- 全ての `derived` の計算式が、元の事実の値から再計算して一致する(機械)。
- `fact` の `quote` が出典に実在する(検査セッション)。確認できないものは `verified: false` のまま残す。
- 探索の計画の全ての問いに、答える事実か「見つからない」の記録がある(機械)。
- 調査依頼の文面が、仮説や結論を含まない(検査セッション)。
- 全ての事実に、全ての仮説に対する `stance` がある(機械)。

網羅したことは証明できない。確かめられるのは、承認した計画に対して漏れがないことまでである。

素材台帳は、この工程で作り、全工程を通じて唯一の事実の置き場とする。スライド上の数値と出典の表記は、台帳から生成する。
